# sf2_player

[English](README.md) | [Русский](README.ru.md)

Консольный кроссплатформенный SoundFont-синтезатор на Rust: ноты с MIDI-клавиатуры (или с двух нижних рядов обычной клавиатуры) проигрываются через выбранный аудиовыход банком SoundFont 2 (.sf2). Интерфейс в терминале перечисляет выбранные устройства, банк, пресет, эффекты и настройки записи по F-клавишам, показывает уровень выходного сигнала и мастер-громкость, а счётчики держит в нижней рамке; игру можно записать в FLAC или Ogg Vorbis. Windows, Linux, macOS; интерфейс на русском или английском.

## Установка

**Готовые бинарники** — вкладка Releases: архивы для Windows x86_64, Linux x86_64, macOS arm64 и x86_64. Распакуйте и запустите `sf2_player`.

**Сборка из исходников** (Rust stable, edition 2024):

```bash
cargo build --release
./target/release/sf2_player --sf2 path/to/bank.sf2
```

Что нужно на машине:

| ОС | Зависимости |
|---|---|
| Windows 10+ | Тулчейн Rust с MSVC (компилятор C нужен для Ogg Vorbis, он входит в Build Tools) |
| Linux | `libasound2-dev` (ALSA, для cpal), `gcc` или `clang`, `pkg-config`; PipeWire и PulseAudio работают через совместимость ALSA |
| macOS 14+ | Xcode Command Line Tools |

Банки SF2 с программой не поставляются. Бесплатные банки General MIDI: GeneralUser GS, FluidR3, TimGM6mb.

### ASIO (Windows, по желанию)

Сборка по умолчанию использует WASAPI в общем режиме. ASIO — отдельная сборка с feature `asio` на вашей машине; в релизные архивы она не входит:

```
cargo build --release --features asio
```

Сверх таблицы выше сборке нужны:

- LLVM с libclang (`winget install LLVM.LLVM`); переменная `LIBCLANG_PATH` на его каталог `bin`. Если первым в `PATH` стоит другой `clang` (например, llvm-mingw), задайте ещё `CLANG_PATH` = `C:\Program Files\LLVM\bin\clang.exe`, иначе `bindgen` падает внутри `mmintrin.h`.
- Visual Studio Build Tools с рабочей нагрузкой C++ (скрипт сборки запускает `vcvarsall.bat`).
- ASIO SDK Steinberg: при первой сборке скачивается в `%TEMP%\asio_sdk`, либо укажите распакованную копию в `CPAL_ASIO_DIR`. У SDK собственная лицензия (`Steinberg ASIO Licensing Agreement.pdf` внутри), она распространяется и на собранный с ним бинарник — поэтому ASIO нет в релизных архивах.

С feature ASIO-драйверы перечисляются в `--list-devices` и диалоге F3 после устройств WASAPI с пометкой `[ASIO]`; выбирайте как любое устройство: `--audio-out "Realtek ASIO"` или `output = "Realtek ASIO [ASIO]"` в конфиге. Без feature или без установленных драйверов список не меняется. ASIO-драйвер монопольный: пока его держит sf2_player, другие программы через него не играют. Поток идёт в формате сэмплов драйвера (Realtek — 24 бит), при отказе от `buffer_frames` действует буфер драйвера (Realtek ASIO принимает только 1024 кадра), а счётчик `xrun` остаётся 0 — cpal не сообщает о недогрузах для ASIO.

## Запуск

```
sf2_player [--sf2 PATH] [--midi-in NAME|INDEX] [--audio-out NAME|INDEX]
           [--buffer FRAMES] [--sample-rate HZ] [--config PATH]
           [--log-level LEVEL] [--ascii] [--list-devices]
```

- `--list-devices` печатает MIDI-входы и аудиовыходы с индексами и выходит; в сборке с feature `asio` после устройств WASAPI идут ASIO-драйверы с пометкой `[ASIO]`.
- Устройства, чью конфигурацию не удалось прочитать (неподдерживаемый ALSA-hint, занятое устройство), пропускаются с предупреждением в логе, а не ломают весь список.
- Устройства выбираются по индексу или по подстроке имени без учёта регистра; если устройство не найдено, берётся системное по умолчанию (первый порт для MIDI) и в строке статуса появляется предупреждение. Если устройство найдено, но открыть его не удалось (занято, неподдерживаемая конфигурация), программа работает без звука, причина показана в строке статуса, а другое устройство выбирается по F3.
- Буфер по умолчанию 256 кадров; если устройство его не принимает, используется буфер по умолчанию.
- Значения из командной строки имеют приоритет над конфигом.

Без `--sf2` программа запускается с тишиной: банк выбирается клавишей F4.

### Текстовая клавиатура

```
  S  D     G  H  J     L  ;        ← чёрные клавиши (C#4 D#4 F#4 G#4 A#4 C#5 D#5)
 Z  X  C  V  B  N  M  ,  .  /     ← белые клавиши  (C4 D4 E4 F4 G4 A4 B4 C5 D5 E5)
```

Ноты играют на MIDI-канале 1 пресетом F5. Снятие ноты зависит от терминала:

- **release** — терминал сообщает об отпускании клавиши: консоль Windows (включая Windows Terminal) и терминалы с kitty keyboard protocol (kitty, WezTerm, foot, Ghostty). Нота звучит, пока клавиша нажата.
- **gate** — остальные терминалы: нота звучит `keyboard.gate_ms` миллисекунд (по умолчанию 300) или до повторного нажатия той же клавиши.

Режим определяется при старте и показан в статусе как `kbd: release` или `kbd: gate 300ms`. Если в вашем терминале ноты «залипают», поставьте `force_gate = true` в секции `[keyboard]`.

## Конфигурация

Файл TOML создаётся при первом выходе из программы и хранит выбранные устройства, банк и последние 10 банков, мастер-громкость, эффекты и формат записи:

| ОС | Путь |
|---|---|
| Windows | `%APPDATA%\sf2_player\config\config.toml` |
| Linux | `~/.config/sf2_player/config.toml` |
| macOS | `~/Library/Application Support/sf2_player/config.toml` |

Лог пишется в локальный каталог данных (`%LOCALAPPDATA%\sf2_player\data\sf2_player.log`, `~/.local/share/sf2_player/`, `~/Library/Application Support/sf2_player/`); уровень задаёт `--log-level`. При каждом запуске удаляется лог предыдущего запуска, поэтому файл всегда описывает один сеанс.

Все поля необязательны; неизвестные ключи игнорируются.

```toml
[midi]
input = "KeyStep"          # подстрока имени или индекс
omni_channel = 1           # все входящие ноты на канал 1 (1–16); убрать — выключить

[audio]
output = "Speakers"        # подстрока имени или индекс; ASIO-устройства — "<драйвер> [ASIO]"
buffer_frames = 256
sample_rate = 48000        # убрать — частота устройства

[synth]
sf2 = "C:/banks/GeneralUser GS.sf2"
preset = [0, 0]            # выбор F5 как [банк, программа]; убрать — первый пресет банка
reverb = true
chorus = false
reverb_level = 40          # посыл CC 91, 0–127
chorus_level = 20          # посыл CC 93, 0–127

[mixer]
master = 80                # 0–100 %

[keyboard]
white = "zxcvbnm,./"       # белые клавиши от C
black = "sdghjl;"          # чёрные клавиши C# D# F# G# A# C# D#
base_octave = 4
velocity = 100
gate_ms = 300
force_gate = false
octave_up = "F11"          # альтернативы для терминалов без Ctrl+стрелок
velocity_down = "Alt+Down"

[keys]                     # команда = сочетание; несколько — через запятую
quit = "F10, Ctrl+Q"
panic = "F9"
rescan = "Alt+F3"

[ui]
lang = "ru"                # "ru" | "en"; убрать — язык системы
ascii = false              # true — индикаторы без Unicode-блоков

[record]
dir = "D:/Music/sf2"       # убрать — папка «Музыка»/sf2_player
format = "flac"            # "flac" | "ogg_vorbis"
vorbis_quality = 0.5       # 0.0–1.0
```

Имена команд для `[keys]`: `help`, `quit`, `focus_next`, `focus_previous`, `midi_dialog`, `audio_dialog`, `sf2_dialog`, `preset_dialog`, `effects_dialog`, `record_dialog`, `rescan`, `record_start`, `record_stop`, `panic`, `octave_up`, `octave_down`, `velocity_up`, `velocity_down`, `notes_off`, `transpose_up`, `transpose_down`, `toggle_reverb`, `toggle_chorus`, `master_up`, `master_down`, `master_up_fast`, `master_down_fast`, `master_mute`. Сочетания: `Ctrl`, `Alt`, `Shift`, затем `F1`–`F24`, `Space`, `Tab`, `Esc`, `Enter`, `Up`/`↑`, `PgUp`, `Home` или один символ. Голая буква запрещена (она нужна нотам), конфликт двух команд на одной клавише — ошибка при запуске с указанием ключа.

## Запись

F7 открывает настройки записи: каталог (Tab дополняет имена каталогов; пусто — каталог по умолчанию) и формат. Home начинает, End останавливает запись; красный индикатор `● ЗАП мм:сс` мигает раз в секунду, пока идёт запись. Файл `ГГГГ-ММ-ДД_ЧЧ-ММ-СС.flac` или `.ogg` появляется в `record.dir` (по умолчанию папка «Музыка»/sf2_player). FLAC пишется без потерь в 24 бита; Ogg Vorbis — с качеством `record.vorbis_quality`. Кодирование идёт в отдельном потоке, аудио-коллбэк только копирует сэмплы в кольцевой буфер; переполнение показывается в статусе как `rec lost N`. Выход во время записи запрашивает подтверждение.

## Индикаторы

- Строки настроек `[F2]`–`[F7]`: выбранный MIDI-вход, аудиовыход (зелёное `OK`, пока поток работает), файл банка, пресет, эффекты, каталог и формат записи. Проблема показывается красным в своей строке (нет устройства, порт отключён, ошибка открытия, банк не указан); сообщения без своей строки (подмена устройства, запись сохранена, конфиг не сохранён) выводятся жёлтым под списком.
- Измеритель: пик и RMS левого и правого каналов в дБFS, обновление 30 раз в секунду, красный `CLIP` держится 1 с после клиппинга.
- Статус в нижней рамке, постоянной ширины — поля не сдвигаются: `голоса 7/64` — число удерживаемых нот и предел полифонии движка (rustysynth не публикует число активных голосов, поэтому релизные хвосты и многослойные пресеты не учитываются); `cpu 3%` — время аудио-коллбэка относительно длительности блока; `xrun` — сбои буфера; `клав:` — режим текстовой клавиатуры, октава и velocity. Транспонирование, omni-канал и счётчики потерь появляются справа в рамке, когда активны и помещаются.
- `--ascii` (или `ui.ascii = true`) заменяет блочные символы на `#`, `-`, `*` для терминалов без Unicode; устаревшая консоль Windows и `TERM=linux`/`dumb` определяются автоматически.

## Задержка

Цель: не более 15 мс от клавиши до звука при буфере 256 кадров и 48 кГц. Как измерить: подключите выход звуковой карты к её входу (или запишите оба сигнала внешним рекордером), запишите одновременно момент нажатия MIDI-ноты и первый ненулевой сэмпл выхода, разница и есть задержка. На Windows сборка по умолчанию использует WASAPI в общем режиме; сборка с feature `asio` может играть через ASIO-драйвер (см. «Установка»). Если задержка велика, проверьте, что устройство принимает буфер 256 (`--list-devices` показывает диапазон) и что в системе нет дополнительной обработки звука. На Linux используйте устройство ALSA `hw:` напрямую, когда это возможно.

## Ограничения

- Воспроизведение и запись MIDI-файлов, SF3 и собственный синтез не входят в версию 1.0.
- Монитора MIDI и полос каналов микшера из версии 1.0 на этом экране нет; громкость каналов следует только входящим CC 7.
- Пресет F5 действует на все каналы, кроме 10 (ударные); Program Change с MIDI-клавиатуры по-прежнему переключает свой канал до следующего выбора в F5, а в шапке остаётся выбор F5.
- Включение или выключение эффектов (F6, Alt+R, Alt+C) пересоздаёт синтезатор: звучащие ноты обрываются. Смена уровня посыла в F6 — нет.
- ASIO — только Windows и только в сборке с feature `asio` (LLVM, MSVC и SDK Steinberg при сборке); релизные архивы собраны без него.
