# sf2_player

[English](README.md) | [Русский](README.ru.md)

Консольный кроссплатформенный SoundFont-синтезатор на Rust: ноты с MIDI-клавиатуры (или с двух нижних рядов обычной клавиатуры) проигрываются через выбранный аудиовыход банком SoundFont 2 (.sf2). Интерфейс в терминале показывает поток MIDI-сообщений, уровень выходного сигнала и микшер; игру можно записать в FLAC или Ogg Vorbis. Windows, Linux, macOS; интерфейс на русском или английском.

## Установка

**Готовые бинарники** — вкладка Releases: архивы для Windows x86_64, Linux x86_64, macOS arm64 и x86_64. Распакуйте и запустите `sf2_player`.

**Сборка из исходников** (Rust stable, edition 2024):

```bash
cargo build --release
./target/release/sf2_player --sf2 path/to/bank.sf2
```

Что нужно на машине:

| ОС | Зависимости |
|---|---|
| Windows 10+ | Тулчейн Rust с MSVC (компилятор C нужен для Ogg Vorbis, он входит в Build Tools) |
| Linux | `libasound2-dev` (ALSA, для cpal), `gcc` или `clang`, `pkg-config`; PipeWire и PulseAudio работают через совместимость ALSA |
| macOS 14+ | Xcode Command Line Tools |

Банки SF2 с программой не поставляются. Бесплатные банки General MIDI: GeneralUser GS, FluidR3, TimGM6mb.

## Запуск

```
sf2_player [--sf2 PATH] [--midi-in NAME|INDEX] [--audio-out NAME|INDEX]
           [--buffer FRAMES] [--sample-rate HZ] [--config PATH]
           [--log-level LEVEL] [--ascii] [--list-devices]
```

- `--list-devices` печатает MIDI-входы и аудиовыходы с индексами и выходит.
- Устройства, чью конфигурацию не удалось прочитать (неподдерживаемый ALSA-hint, занятое устройство), пропускаются с предупреждением в логе, а не ломают весь список.
- Устройства выбираются по индексу или по подстроке имени без учёта регистра; если устройство не найдено, берётся системное по умолчанию (первый порт для MIDI) и в строке статуса появляется предупреждение. Если устройство найдено, но открыть его не удалось (занято, неподдерживаемая конфигурация), программа работает без звука, причина показана в строке статуса, а другое устройство выбирается по F3.
- Буфер по умолчанию 256 кадров; если устройство его не принимает, используется буфер по умолчанию.
- Значения из командной строки имеют приоритет над конфигом.

Без `--sf2` программа запускается с тишиной: банк выбирается клавишей F4.

### Текстовая клавиатура

```
  S  D     G  H  J     L  ;        ← чёрные клавиши (C#4 D#4 F#4 G#4 A#4 C#5 D#5)
 Z  X  C  V  B  N  M  ,  .  /     ← белые клавиши  (C4 D4 E4 F4 G4 A4 B4 C5 D5 E5)
```

Ноты играют на текущем канале микшера. Снятие ноты зависит от терминала:

- **release** — терминал сообщает об отпускании клавиши: консоль Windows (включая Windows Terminal) и терминалы с kitty keyboard protocol (kitty, WezTerm, foot, Ghostty). Нота звучит, пока клавиша нажата.
- **gate** — остальные терминалы: нота звучит `keyboard.gate_ms` миллисекунд (по умолчанию 300) или до повторного нажатия той же клавиши.

Режим определяется при старте и показан в статусе как `kbd: release` или `kbd: gate 300ms`. Если в вашем терминале ноты «залипают», поставьте `force_gate = true` в секции `[keyboard]`.

## Конфигурация

Файл TOML создаётся при первом выходе из программы и хранит выбранные устройства, банк и последние 10 банков, мастер-громкость, эффекты и формат записи:

| ОС | Путь |
|---|---|
| Windows | `%APPDATA%\sf2_player\config\config.toml` |
| Linux | `~/.config/sf2_player/config.toml` |
| macOS | `~/Library/Application Support/sf2_player/config.toml` |

Лог пишется в локальный каталог данных (`%LOCALAPPDATA%\sf2_player\data\sf2_player.log`, `~/.local/share/sf2_player/`, `~/Library/Application Support/sf2_player/`); уровень задаёт `--log-level`.

Все поля необязательны; неизвестные ключи игнорируются.

```toml
[midi]
input = "KeyStep"          # подстрока имени или индекс
omni_channel = 1           # все входящие ноты на канал 1 (1–16); убрать — выключить

[audio]
output = "Speakers"
buffer_frames = 256
sample_rate = 48000        # убрать — частота устройства

[synth]
sf2 = "C:/banks/GeneralUser GS.sf2"
reverb = true
chorus = false
reverb_level = 40          # посыл CC 91, 0–127
chorus_level = 20          # посыл CC 93, 0–127

[mixer]
master = 80                # 0–100 %

[keyboard]
white = "zxcvbnm,./"       # белые клавиши от C
black = "sdghjl;"          # чёрные клавиши C# D# F# G# A# C# D#
base_octave = 4
velocity = 100
gate_ms = 300
force_gate = false
octave_up = "F11"          # альтернативы для терминалов без Ctrl+стрелок
velocity_down = "Alt+Down"

[keys]                     # команда = сочетание; несколько — через запятую
quit = "F10, Ctrl+Q"
panic = "F9"
select_channel_3 = "Alt+F3"

[ui]
lang = "ru"                # "ru" | "en"; убрать — язык системы
ascii = false              # true — индикаторы без Unicode-блоков

[record]
dir = "D:/Music/sf2"       # убрать — папка «Музыка»/sf2_player
format = "flac"            # "flac" | "ogg_vorbis"
vorbis_quality = 0.5       # 0.0–1.0
```

Имена команд для `[keys]`: `help`, `quit`, `focus_next`, `focus_previous`, `midi_dialog`, `audio_dialog`, `sf2_dialog`, `preset_dialog`, `effects_dialog`, `record_dialog`, `rescan`, `record_start`, `record_stop`, `panic`, `octave_up`, `octave_down`, `velocity_up`, `velocity_down`, `notes_off`, `transpose_up`, `transpose_down`, `toggle_reverb`, `toggle_chorus`, `monitor_clear`, `monitor_pause`, `master_up`, `master_down`, `master_up_fast`, `master_down_fast`, `master_mute`, `select_channel_1` … `select_channel_16`, `channel_up`, `channel_down`, `channel_mute`, `channel_solo`, `scroll_up`, `scroll_down`, `page_up`, `page_down`. Сочетания: `Ctrl`, `Alt`, `Shift`, затем `F1`–`F24`, `Space`, `Tab`, `Esc`, `Enter`, `Up`/`↑`, `PgUp`, `Home` или один символ. Голая буква запрещена (она нужна нотам), конфликт двух команд на одной клавише — ошибка при запуске с указанием ключа.

## Запись

F7 открывает настройки записи: каталог (Tab дополняет имена каталогов; пусто — каталог по умолчанию) и формат. Home начинает, End останавливает запись; красный индикатор `● ЗАП мм:сс` мигает раз в секунду, пока идёт запись. Файл `ГГГГ-ММ-ДД_ЧЧ-ММ-СС.flac` или `.ogg` появляется в `record.dir` (по умолчанию папка «Музыка»/sf2_player). FLAC пишется без потерь в 24 бита; Ogg Vorbis — с качеством `record.vorbis_quality`. Кодирование идёт в отдельном потоке, аудио-коллбэк только копирует сэмплы в кольцевой буфер; переполнение показывается в статусе как `rec lost N`. Выход во время записи запрашивает подтверждение.

## Индикаторы

- Монитор MIDI: последние 200 сообщений с временем, каналом, типом, данными и именем ноты. Ctrl+F замораживает прокрутку (сообщения продолжают накапливаться), Ctrl+L очищает.
- Измеритель: пик и RMS левого и правого каналов в дБFS, обновление 30 раз в секунду, красный `CLIP` держится 1 с после клиппинга.
- Статус: `voices 7/64` — число удерживаемых нот и предел полифонии движка (rustysynth не публикует число активных голосов, поэтому релизные хвосты и многослойные пресеты не учитываются); `cpu 3%` — время аудио-коллбэка относительно длительности блока; `xruns` — сбои буфера.
- `--ascii` (или `ui.ascii = true`) заменяет блочные символы на `#`, `-`, `*` для терминалов без Unicode; устаревшая консоль Windows и `TERM=linux`/`dumb` определяются автоматически.

## Задержка

Цель: не более 15 мс от клавиши до звука при буфере 256 кадров и 48 кГц. Как измерить: подключите выход звуковой карты к её входу (или запишите оба сигнала внешним рекордером), запишите одновременно момент нажатия MIDI-ноты и первый ненулевой сэмпл выхода, разница и есть задержка. На Windows используется WASAPI в общем режиме (ASIO не поддерживается); если задержка велика, проверьте, что устройство принимает буфер 256 (`--list-devices` показывает диапазон) и что в системе нет дополнительной обработки звука. На Linux используйте устройство ALSA `hw:` напрямую, когда это возможно.

## Ограничения

- Воспроизведение и запись MIDI-файлов, SF3 и собственный синтез не входят в версию 1.0.
- Входящие CC 7 с MIDI-клавиатуры меняют громкость в движке, но не отражаются в микшере до следующего действия в нём.
- Включение или выключение эффектов (F6, Alt+R, Alt+C) пересоздаёт синтезатор: звучащие ноты обрываются. Смена уровня посыла в F6 — нет.
