# Правка fix1 — главный экран

Постановка: `docs/fix/fix1.md` (пять пунктов владельца, снимок `docs/fix/ui.png`). Выполнено 2026-11-18.
Этапы ТЗ, плана и верификации не проводились: постановка дана владельцем списком правок.

## Что сделано

| Пункт fix1 | Сделано | Где |
|---|---|---|
| 1. Рамка, название и версия, состояние, отступы | Одинарная рамка вокруг всей сетки (`Block` из `gterm-widgets`). На верхней линии слева `sf2_player`, справа версия; на нижней — счётчики слева и `движок: …` справа; всё — через одну ячейку от угла. Содержимое отстоит от рамки на 2 ячейки по горизонтали и на 1 строку по вертикали; строки, которые не помещаются, обрезаются у отступа | `src/ui/main_screen.rs` |
| 2. Клавиатура по шаблону | Пианино 41×4: чёрные клавиши `│s│` с ножкой `└┬┘`, белые `│ z │`, под ними линия `└───┴───┘` (добавлена вторым заходом); буквы берутся из раскладки текстовой клавиатуры (`[keyboard]` конфига). У звучащей ноты подсвечена буква: тёмная на янтарном фоне | `src/ui/piano.rs`, `src/ui/text_keyboard.rs` |
| 3. Названия разделов на линии | Линия раздела `─ НАЗВАНИЕ ────`; над линией и под ней пустая строка. «Обработчик» → «Движок», «Аудио-файл» → «Запись» (en: Engine, Recording) | `src/ui/main_screen.rs`, `locales/app.yml` |
| 4. «Выход» и «Запись» внизу | Оба раздела отсчитываются от нижней линии рамки при любой высоте окна. Вторым заходом опущены на строку: строка «Запись» стоит прямо над строкой отступа, а сообщение без своей строки (запись сохранена или отменена, шрифт заменён) пишется в строке отступа | `src/ui/main_screen.rs` |
| 5. Блок «Запись» | Подписи с двоеточием, выровнены по правому краю колонки подписей. «Папка для файлов:» — кнопка с путём (нажатие открывает тот же диалог папки; длинный путь теряет начало). «Формат:» — выпадающий список FLAC / OGG / MIDI; пока идёт запись, поле затемнено и не раскрывается. Строка «Запись:» без изменений | `src/ui/main_screen/output.rs`, `src/ui/controls.rs`, `src/ui/app.rs`, `src/ui/window/layers.rs` |

Следствия:

- Минимальная сетка — 96×36 (была 96×31): рамка, отступы, две новые строки пианино и пустые строки у линий занимают пять строк сверх прежнего.
- Кнопки `[FLAC]` `[OGG]` `[MIDI]` и вид кнопки «выбрана и заперта» убраны; ключи словаря `app.title` и `main.folder` удалены как неиспользуемые.
- Оба README, `AGENTS.md` и `PROJECT_MAP.md` приведены к новому экрану.

## Не закрыто

- Вживую не проверены действия: выбор формата из списка мышью и клавишами, подсветка буквы при нажатии клавиши, растягивание окна. Проверен только вид неподвижного окна.
- В списке формата подсказка справа («запись аудиопотока» / «запись MIDI-событий») сохранена, хотя в наброске fix1 её нет: в документе об её удалении не сказано.
- Слово «обработчик» осталось в справке (`help.action.engine_toggle`), в текстах README и в ADR: переименован только заголовок раздела, как сказано в fix1.
- ТЗ v1.2 §3 по-прежнему называет минимальную сетку 96×31 и прежний вид экрана: документы ТЗ не правились.
- Тесты справки проверяют прокрутку на собственной сетке 24 строки: при 36 строках таблица привязок по умолчанию (28 строк) помещается в окно справки целиком.
- Linux не проверялся.
