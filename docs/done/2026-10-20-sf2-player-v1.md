## Шаг 1.4 — audio/: устройства cpal, поток, коллбэк (2026-10-20)

**Сделано**

- `src/audio/shared.rs`: `AudioShared` — мастер-гейн (биты f32 в `AtomicU32`, clamp 0..1) и счётчик xrun; единственный канал audio → другие потоки, как требует ADR 0002.
- `src/audio/render.rs`: `BlockRenderer` — ядро коллбэка: вычитывает `MidiEvent` из SPSC-кольца, применяет к `SynthEngine`, рендерит чанками ≤ 4096 кадров в заранее выделенные буферы, применяет гейн и интерливит в выход (моно — среднее L/R, каналы > 2 — тишина). Без аллокаций и блокировок после `new`.
- `src/audio/device.rs`: `list_output_devices()` (индекс, имя, признак умолчания, частота, диапазон буфера), `default_output_device()`.
- `src/audio/stream.rs`: `open_output_stream` — stereo f32, частота из CLI или устройства, `BufferSize::Fixed(n)` с настоящим fallback на `Default` (F-04); движок и кольцо создаются внутри каждой попытки, потому что cpal забирает замыкания даже при неудаче; возвращает поток и производителя кольца (ёмкость 1024). Ошибки cpal с `ErrorKind::Xrun` считаются в `AudioShared`, остальные — в лог.
- `main.rs`: `--list-devices` печатает аудиовыходы и выходит; с `--sf2` открывает поток на устройстве по умолчанию и ждёт Enter (временный режим до TUI), по выходу печатает число xrun.

**COMPLETENESS** — F-03 перечисление: код + ручная проверка; F-04 поток и fallback: код, ручная проверка основного пути; ядро коллбэка: код + 7 тестов; `AudioShared`: 2 теста.

**CORRECTNESS** — тесты ядра: тишина без событий, нота из кольца звучит на L и R, гейн 0 даёт тишину, моно и 4-канальный выход, буфер длиннее чанка (8315 кадров) обрабатывается целиком, note off через кольцо гасит звук.

**EVIDENCE** — `cargo fmt --check` ok; `cargo clippy --all-targets -- -D warnings` чисто; `cargo test`: 42 passed, 0 failed (0.12 s). Живые проверки на Windows: `--list-devices` → «* [0] Динамики (Realtek(R) Audio) 48000 Hz, buffer 480..480 frames»; воспроизведение 2 с с буфером 256 и 1 с с буфером 64 → exit 0, xruns 0, лог `audio stream started … buffer_size=Fixed(256|64)`. LOC: render.rs 224, stream.rs 100, shared.rs 65, device.rs 51, main.rs 63.

**⚠ WARNINGS**
