# План реализации: редизайн главного экрана (v1.1)

- **id:** `2026-10-21-ui-redesign`
- **ТЗ:** `docs/spec/2026-10-21-ui-redesign.md` (открытые решения приняты владельцем 21.10.2026)
- **Статус плана:** выполнен 2026-10-21 (шаги 1–5; верификация — `docs/verify/2026-10-21-ui-redesign.md`)
- **Дата:** 2026-10-21

## 1. Рамки

**Входит:** всё из ТЗ v1.1 §2–§5: новый макет главного экрана, диалоги F6 (эффекты) и F7 (запись), клавиши Home/End, глобальный пресет F5, статус в нижней рамке, удаление монитора MIDI и полос каналов, README ×2, ADR, PROJECT_MAP.

**Не входит:** движок, аудио/MIDI-потоки, форматы записи, текстовая клавиатура, CLI; монитор MIDI в модальном окне (бэклог).

## 2. Открытые решения (AR-04)

Все три приняты владельцем 21.10.2026 (ТЗ §6): ОР-1 → A (ADR 0011), ОР-2 → B (ADR 0010), ОР-3 → диалог. ADR пишутся на шаге, где решение применяется: 0010 — шаг 4, 0011 — шаг 3.

**Принятые допущения** (локальные, обратимые — BP-02.3):

- A-1. «rfrf» в конце постановки — опечатка, не требование.
- A-2. Стандартная авторизация владельца на коммит после каждого шага действует и для этого плана (память `autonomous-commit-per-step`).
- A-3. Удаление монитора (ОР-2 B) включает весь путь данных F-08: `ui/monitor.rs`, `midi/monitor.rs`, кольцо MIDI→UI в `Session` и `MidiSink`; полуживой путь без потребителя хуже отсутствующего.
- A-4. Канальная часть микшера (`ChannelStrip`, mute/solo) удаляется из `audio/mixer.rs`; `push_channel_volumes` при установке движка больше не нужен (CC 7 остаётся на умолчании GM 100 внутри движка).
- A-5. Версия пакета не меняется (0.1.0); заголовок берёт `CARGO_PKG_VERSION`.

- Справка F1 = таблица README = `keys::BINDINGS` (`readme_keys`).
