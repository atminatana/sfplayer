## 3. Архитектурный каркас (из ТЗ, уточнения для реализации)

```
MIDI-поток (midir callback)          UI-поток (ratatui, цикл 16–33 мс)
   │ parse → MidiEvent                   │ ввод crossterm → AppState
   ├─ SPSC ring  midi_events ─────┐      ├─ SPSC ring  ui_commands ──────┐
   └─ SPSC ring  monitor_midi ─┐  │      │   (Command::{Midi, Gain, Mute,  │
                               │  │      │     Program, Panic, Reverb…})   │
                               ▼  ▼      ▼                                ▼
                        UI читает   Аудио-поток (cpal callback):
                        монитор +     drain midi_events + ui_commands
                        атомики       → SynthEngine → render(L,R) → mixer gain
                                      → meters (atomics: peak/rms L/R, voices,
                                        cpu %, xruns) → SPSC ring rec_samples
                                                              │
                                                              ▼
                                                   Поток записи (flacenc / vorbis_rs)
```

Модули: `main.rs`, `cli.rs`, `config.rs`, `midi/{mod,parse,ports,hotplug}.rs`, `audio/{mod,device,stream,mixer,meter}.rs`, `synth/{mod,engine,rusty}.rs`, `ui/{mod,app,keys,i18n,widgets/*,dialogs/*}.rs`, `record/{mod,flac,vorbis}.rs`, `locales/{ru,en}.yml`.

Инварианты, проверяемые на каждом шаге (ТЗ N-03, §6):

- в аудио-коллбэке нет `alloc`, `Mutex`, `println!`, `tracing` — только `try_pop`/`try_push`, атомики и срезы фиксированного размера;
- все строки UI — через `t!()`, grep по литералам кириллицы/латиницы в `ui/` пуст;
- `cargo clippy -- -D warnings`, `cargo fmt --check`, `cargo test` зелёные перед завершением шага (QG).

## 6. Риски плана (сверх ТЗ §9)

| Риск | Влияние | Снижение |
|------|---------|----------|
| `assets/sin_wave.sf2` (1,2 КБ) может не загрузиться в rustysynth или дать тишину | Оффлайн-тесты этапа 1 без ассета | Проверяется первым на шаге 1.2; при неудаче — сгенерировать минимальный SF2 тестовой утилитой или взять свободный банк в тестовые ресурсы |

| Сроки ТЗ (15–19 дней) оценивались до добавления F-16, F-19, F-20 в M | Этапы 4–5 длиннее оценки | Этап 5 может быть разбит на два релиза: 1.0 (без записи Vorbis) и 1.1 — решение владельца по ходу |
