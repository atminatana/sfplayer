## 1. Рамки

**Входит:** всё из ТЗ v1.2: доработки gterm G-1 (тик) и G-2 (измеритель); замена фронтенда ratatui → gterm; экран §3; мышь и кольцо фокуса (F-25); текстовая клавиатура на физических кодах (F-16); пианино и карта нот (F-24); встроенный Synth с ревербом и хорусом (F-22); MIDI-файл (F-21); запись MIDI и отмена записи (F-23); оконная подсистема Windows и лог по ключу (N-07); CI на двух ОС; README ×2, AGENTS.md, ADR, PROJECT_MAP, верификация.

- A-6. Версия пакета поднимается до 0.2.0 на шаге 7.1.

## 4. Инварианты

- Аудио-коллбэк без аллокаций, блокировок и системных вызовов (N-03): новые кольца и атомики создаются вне коллбэка; каждый шаг этапов 3–6, меняющий `audio/render.rs`, сохраняет зелёными его прежние тесты.
- Сигнатура трейта `SynthEngine` не меняется.
- Все строки интерфейса — через словарь; `tests/i18n_completeness.rs` зелёный после каждого шага.
- Справка F1 = таблицы README = таблица привязок (`readme_keys`).
- Старые конфиги открываются: неизвестные поля игнорируются (`config.rs`, тест `unknown_keys_and_partial_sections_are_tolerated`), имена команд `[keys]` не исчезают (A-3).
- UI-тесты не открывают окно: только `ScreenBuffer` и маршрутизация `Ui`; всё, что требует окна, — в ручные проверки отчёта.
- В `gterm-git` — правила того репозитория; с `D:\Roman\Rust\gterm` работа не ведётся.

## 5. Риски

- **Размер бинарника.** gterm приносит winit, glutin, usvg, fontdb, rayon; сейчас 3,6 МБ при лимите 10 МБ (N-12). Замер — шаг 1.2; при превышении — владельцу до продолжения.
- **Лицензии — риск снят 13.11.2026.** Отчёт снят на шаге 1.2; владелец принял BSL-1.0, ISC, BSD-2-Clause, BSD-3-Clause и Zlib наравне с MIT/Apache (ТЗ N-11). Уточнение записывается в ADR шага 1.4.
- **Linux.** Состав системных пакетов для сборки и CI неизвестен до первой сборки; буфер обмена на Wayland без XWayland в gterm ограничен (`TODO.md` gterm); живая проверка на Linux — только вручную.
- **Клавиши с Shift.** winit сообщает модификаторы иначе, чем терминал; привязки громкости (`+`, `=`, `_`) проверяются тестами шага 1.4 на физических клавишах.
- **Шаг 1.4 крупный** (удаление старого интерфейса и перевод клавиатуры): если гейты не сходятся за один проход, текстовая клавиатура выносится в отдельный коммит 1.4б.
