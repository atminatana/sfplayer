# ТЗ: редизайн главного экрана sf2\_player (v1.1)

Oct 21, 2026 · черновик агента по постановке владельца; открытые решения ОР-1…ОР-3 приняты владельцем 21.10.2026 (§6) — ТЗ считается утверждённым с этими ответами. Базовое ТЗ — `docs/spec/2026-10-20-sf2-player-v1.md`; этот документ меняет его §6 (макет, часть клавиш), семантику F-06 (пресет), F-20 (запись) и выводит F-08 (монитор MIDI) и канальную часть F-10 из v1.1; остальные разделы v1 остаются в силе.

## 1. Цель

Главный экран становится списком настроек «клавиша → значение → состояние» вместо четырёх панелей: пользователь сразу видит, что выбрано (MIDI, аудио, банк, пресет, эффекты, запись) и что из этого сломано — ошибка пишется красным в той же строке, где стоит сломанная настройка. Микшер сокращается до измерителя L/R и мастер-громкости; счётчики переезжают в нижнюю рамку; запись получает диалог настроек и отдельные клавиши старт/стоп.

Вне области: движок синтеза, аудио/MIDI-потоки, форматы записи, текстовая клавиатура (F-16) и её клавиши, CLI, формат конфига (кроме полей из §5).

Нижняя рамка — одна строка; заголовок `sf2_player <версия>` — по центру верхней рамки. Монитора MIDI и полос 16 каналов на экране нет (ОР-2).

Состояния строк:

| Строка | Норма | Ошибка (красным, в той же строке) |
| --- | --- | --- |
| F2 MIDI | имя порта, без пометок | «нет устройства» (порт не выбран / портов нет); «<порт> (отключено)»; текст ошибки открытия |
| F3 Аудио | `<устройство> <частота> Hz / <N> кадров` + зелёное `OK` | «нет устройства»; текст ошибки открытия потока (`notice.no_audio_device`, `notice.audio_error`) |
| F4 SF2 | имя файла (без каталога); число пресетов — в диалоге F5, не здесь | «не указан»; «файл не найден: <путь>»; текст ошибки загрузки (`notice.sf2_error`) |
| F5 Пресет | `bank:program имя` | — (без банка — серым «нет банка») |
| F6 Эффекты | `рев <уровень или выкл>  хор <уровень или выкл>` | — |
| F7 Запись | `<каталог>  <FLAC или Ogg Vorbis>`; во время записи справа красным `● ЗАП mm:ss`, точка мигает (период 1 с) | текст ошибки записи (`notice.record_error`) |

Уведомления, не привязанные к строке (запись сохранена, конфиг не сохранён, fallback на устройство по умолчанию), показываются жёлтым в строке сообщений под блоком F1–F7 до следующего уведомления или действия пользователя.

## 3. Клавиши — изменения относительно §6 v1

| Клавиша | Было (v1) | Становится |
| --- | --- | --- |
| F6 | диалог формата записи | диалог эффектов (§4.2) |
| F7 | старт/стоп записи | диалог настроек записи (§4.3) |
| Home / End | начало/конец списка (диалоги), прокрутка монитора | **на главном экране**: Home — начать запись, End — остановить; в диалогах — как раньше (диалог получает клавиши первым) |
| Tab / Shift+Tab | фокус панели | удаляются вместе с фокусом панелей |
| 1–9 0, Alt+1–6, ← →, Ctrl+X, Ctrl+O | канал микшера | удаляются вместе с полосами каналов; ← → свободны |
| Ctrl+L, Ctrl+F, ↑ ↓, PgUp, PgDn | монитор MIDI | удаляются вместе с монитором; в диалогах ↑ ↓ PgUp PgDn работают как раньше |

Без изменений: F1, F2, F3, F4, F5 (клавиша та же, семантика — §4.1), F8, F9/Space, F10/Ctrl+C, + −, Ctrl+U, [ ], Alt+R/Alt+C, Ctrl+↑↓←→, Esc, текстовая клавиатура. `[keys]` в конфиге продолжает работать; имена удалённых команд в конфиге дают ошибку `UnknownCommand`, как любое незнакомое имя.

## 4. Функциональные требования

### 4.1 F5 — пресет по умолчанию (меняет F-06)

- Диалог-селектор как в v1 (список `bank:program имя`, фильтр по набранному тексту, Enter/Esc).
- После загрузки банка пресет по умолчанию — первый в списке пресетов банка (как сейчас при пустом выборе).
- Выбор в F5 применяется **ко всем 16 каналам** (Bank Select + Program Change на каждый канал), кроме канала 10 — ударные, банк 128 (ОР-1 A).
- Program Change, пришедший с MIDI-устройства, по-прежнему меняет пресет своего канала (F-07) до следующего выбора в F5; строка F5 показывает выбор пользователя, а не состояние канала.
- Выбор сохраняется в конфиг (`synth.preset = [bank, program]`, F-14) и восстанавливается при старте, если банк тот же и пресет в нём есть.

### 4.2 F6 — диалог эффектов (F-13)

Модальное окно с двумя строками: `Реверб  [x]  уровень  40`, `Хорус   [ ]  уровень   0`. ↑↓ — выбор строки, Space — вкл/выкл, ← → — уровень ±5 (0..=127), Enter — закрыть с сохранением в конфиг (`synth.reverb`, `synth.chorus`, `synth.reverb_level`, `synth.chorus_level`), Esc — отмена с откатом. Изменения уровня применяются сразу (CC 91/93), включение/выключение — как сейчас по Alt+R/Alt+C. Alt+R / Alt+C на главном экране остаются.

### 4.3 F7 — диалог записи (меняет F-20)

Модальное окно: поле «Каталог:» (как поле пути F4: курсор, ←→/Home/End, вставка, автодополнение каталогов по Tab; пустое поле = каталог музыки ОС, как сейчас при `record.dir = None`) и строка «Формат: (•) FLAC  ( ) Ogg Vorbis» с описанием формата из v1 под ней; ↑↓ — переход между полем и строкой формата, ← → — переключение формата, Enter — применить и сохранить (`record.dir`, `record.format`), Esc — отмена. Если каталог не существует — он создаётся при старте записи; ошибка создания показывается в строке F7 красным. Имя файла — как в v1 (`YYYY-MM-DD_HH-MM-SS.<ext>`).

Home — начать запись (повторный Home во время записи игнорируется), End — остановить. Индикатор: `● ЗАП mm:ss` красным в строке F7, точка мигает с периодом 1 с; при остановке в строке сообщений — «Запись сохранена: <имя>». Подтверждение выхода во время записи — как в v1.

### 4.4 Нижняя рамка — статус (F-12, F-16)

Текст в нижней рамке слева, ширина постоянна при любых значениях:

```
Голоса {held:>3}/{max:<3}  cpu {cpu:>3}%  xrun {xrun:>5}  клав: {mode:<14}  окт {oct:>1}  vel {vel:>3}
```

- `held`/`max` — 0..=999, без движка `  -/-  `; `cpu` — 0..=100; `xrun` — до 99999, дальше `9999+`.
- `mode` — «отпускание» / «gate 300мс», дополняется пробелами до 14 знаков (en: «release» / «gate 300ms»).
- Необязательные поля (транспонирование `тр +3`, `omni к1`, `потеряно N`, `зап. потеряно N`) добавляются **после** обязательных, поэтому не сдвигают их.

### 4.5 Микшер (F-09, F-10)

Заголовок «Микшер», измеритель L/R (пик/RMS в дБFS, CLIP с удержанием 1 с — как сейчас), строка `МАСТЕР <полоса> NN%` с пометкой `тихо` при mute. Полосы 16 каналов, mute/solo канала и их клавиши удалены (ОР-2 B); громкость каналов остаётся на значении GM по умолчанию (CC 7 = 100).

### 4.6 Общее

- Все новые строки — в `locales/app.yml` (ru/en), тест полноты словаря проходит.
- Снэпшот 80×24 обновляется под новый макет; тест `readme_keys` и обе README — под новую таблицу клавиш.
- Справка F1 генерируется из той же таблицы привязок и совпадает с раскладкой.
- Частота перерисовки ≤ 30 кадров/с; мигание индикатора — на таймере цикла UI, без отдельного потока.
- Монитор MIDI (F-08) выходит из v1.1 целиком: панель, состояние UI и кольцо MIDI→UI удаляются; возврат — отдельной задачей из бэклога.

## 5. Конфиг

Новые/изменённые поля: `synth.preset = [bank, program]` (ОР-1). Остальное используется существующее: `record.dir`, `record.format`, `synth.reverb*`, `synth.chorus*`. Удалённых полей нет; имена команд `[keys]` удалённых клавиш (`focus_next`, `select_channel_*`, `channel_*`, `monitor_*`, `scroll_*`, `page_*`, `record_format_dialog`, `record`) больше не принимаются.

## 7. Критерии приёмки

- [ ] Снэпшот 80×24 совпадает с макетом §2; заголовок по центру, статус в нижней рамке
- [ ] Ошибка MIDI / аудио / SF2 видна красным в своей строке; при исправлении исчезает; аудио без ошибки показывает зелёное OK
- [ ] F5 меняет пресет на всех каналах, кроме 10: оффлайн-тест через `assets/sin_wave.sf2` подтверждает Program Change на каналах 1 и 16 и его отсутствие на 10
- [ ] F6: включение/уровень реверба и хоруса меняются из диалога и сохраняются в конфиг
- [ ] F7: каталог и формат меняются из диалога и сохраняются; Home начинает запись, End останавливает, файл появляется в указанном каталоге; индикатор мигает
- [ ] Строка статуса не меняет ширину при `held` 0→999, `xrun` 0→99999, смене режима клавиатуры
- [ ] Справка F1 и таблицы в `README.md` / `README.ru.md` совпадают с новой раскладкой (`readme_keys` зелёный)
- [ ] `cargo fmt --check && cargo clippy --all-targets -- -D warnings && cargo test` зелёные
