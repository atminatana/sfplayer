# 0011. Пресет F5 — один на все каналы, кроме ударных

- **Дата:** 2026-10-21
- **Статус:** Accepted (ОР-1 ТЗ v1.1, принято владельцем)
- **Тема:** семантика выбора пресета (отклонение от F-06 ТЗ v1)

## Контекст

F-06 v1 выбирал пресет «для текущего канала» микшера. В редизайне v1.1 полосы каналов и понятие текущего канала с экрана уходят (ADR 0010), а владелец описал F5 как «пресет по умолчанию из sf2, используется для всех каналов».

## Решение

`Session::select_preset(bank, program)` шлёт Bank Select + Program Change на каналы 1–16, кроме 10 (ударные: в SF2 банк 128 подразумевается каналом 10, перебивать его мелодическим пресетом бессмысленно). Program Change с MIDI-устройства по-прежнему меняет свой канал (F-07) до следующего выбора в F5; шапка показывает выбор пользователя, а не состояние каналов. Выбор хранится в `synth.preset = [bank, program]` и восстанавливается при старте, если загружен тот же банк и пресет в нём есть; другой банк начинает с первого пресета.

## Альтернативы и обоснование

- Оставить пресет на канал (v1) — без полос каналов пользователь не видит и не выбирает канал; клавиатура играет на канале 1, MIDI-устройство — на своём: «один инструмент на всё» ожидаемее.
- Применять и на канал 10 — ломает ударные у GM-клавиатур; исключение канала 10 стоит одной проверки.
- Хранить пресет per-channel в конфиге — лишняя структура ради сценария, которого больше нет в UI.

## Последствия

- (+) Одна строка «Пресет:» в шапке, одно поле конфига, 30 сообщений в кольцо (ёмкость 256).
- (−) Нельзя задать разные пресеты на разные каналы из UI — только Program Change с устройства. Возврат к per-channel — отдельная задача с полосами каналов.
