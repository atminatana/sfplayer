# 0006. Имя пакета и бинарника: sf2_player

- **Дата:** 2026-10-20
- **Статус:** Accepted (OD-1 плана, принято владельцем)
- **Тема:** именование

## Контекст

Cargo-пакет создан как `sfplayer`; ТЗ везде использует `sf2_player`: команда запуска, каталог конфига `%APPDATA%\sf2_player`, заголовок TUI.

## Решение

Пакет и бинарник переименовываются в `sf2_player`. Имя каталога конфига, лог-файла и заголовка TUI — `sf2_player`. Каталог репозитория `sfplayer` не переименовывается.

## Альтернативы и обоснование

- Пакет `sfplayer` + `[[bin]] name = "sf2_player"` — два имени в одном проекте, путаница в `cargo run -p`.
- Оставить `sfplayer` и править ТЗ — ТЗ утверждено заказчиком, имя там выбрано осознанно.

Переименование до первой строки кода бесплатно.

## Последствия

- (+) Одно имя в ТЗ, бинарнике, конфиге, логах.
- (−) Имя каталога репозитория отличается от имени пакета — допустимо.
