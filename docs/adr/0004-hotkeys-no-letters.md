# 0004. Горячие клавиши без букв: F-клавиши и Ctrl/Alt

- **Дата:** 2026-10-20
- **Статус:** Accepted
- **Тема:** раскладка управления в TUI

## Контекст

F-16 требует играть ноты с двух нижних рядов клавиатуры (Z–/ и S–;) всегда, без отдельного режима. Буквенные команды конфликтовали бы с нотами.

## Решение

Команды висят только на F1–F10, Ctrl/Alt-сочетаниях, цифрах и небуквенных клавишах (таблица ТЗ §6). Пересканирование устройств — F8; упоминание «клавиша r» в ТЗ §9 считается устаревшим. Справка F1 и README генерируются из той же таблицы привязок, что и обработчик ввода (единый источник).

## Альтернативы и обоснование

- Режим «игра/команды» с переключателем — лишний шаг для пользователя, риск забыть режим; отклонён заказчиком (ТЗ §9).

## Последствия

- (+) Нет пересечений между игрой и управлением.
- (−) Ctrl+M/I/H/J не используются (совпадают с Enter/Tab/Backspace/LF); часть терминалов не передаёт Ctrl+стрелки — альтернативы задаются в `[keyboard]` (ADR 0007).
