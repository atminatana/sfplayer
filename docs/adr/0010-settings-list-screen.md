# 0010. Главный экран — список настроек; монитор MIDI и полосы каналов убраны

- **Дата:** 2026-10-21
- **Статус:** Accepted (ОР-2 ТЗ v1.1, принято владельцем)
- **Тема:** макет главного экрана и состав клавиш (отклонение от ТЗ v1 §6, F-08, канальной части F-10)

## Контекст

Экран v1 состоял из четырёх панелей (шапка, монитор MIDI, микшер на 16 каналов, статус) с фокусом по Tab и контекстными клавишами. Владелец предложил экран-список: каждая настройка — строка с её F-клавишей и состоянием, ошибки — красным в той же строке, счётчики — в нижней рамке. В постановке нет ни монитора, ни полос каналов; на вопрос «оставить или убрать» владелец выбрал «убрать и монитор, и полосы».

## Решение

- Главный экран: заголовок по центру верхней рамки, строки `[F1]…[F7]` (справка, MIDI, аудио, SF2, пресет, эффекты, запись), строка `[Home]/[End]`, строка сообщений (жёлтым), блок «Микшер» (L/R, мастер), статус в нижней рамке: обязательные поля постоянной ширины слева, необязательные справа, если помещаются.
- Ошибки привязаны к строкам: `MidiError` → F2, `NoAudioDevice`/`AudioError` → F3, `Sf2Error` → F4, `RecordError` → F7; остальные уведомления — в строку сообщений. Аудио без ошибки — зелёное `OK`.
- Монитор MIDI (F-08) удалён целиком: панель, состояние UI (`ui/monitor.rs`), формат записей (`midi/monitor.rs`), кольцо MIDI→UI и его счётчик потерь. Полосы 16 каналов, mute/solo, `current_channel` и их клавиши удалены; `Mixer` — только мастер.
- Клавиши: Tab/Shift+Tab, ↑↓/PgUp/PgDn на главном экране, Ctrl+L/Ctrl+F, 1–0/Alt+1–6, ←→, Ctrl+X/Ctrl+O убраны; F6 — диалог эффектов, F7 — диалог записи, Home/End — старт/стоп записи. Фокуса панелей больше нет.

## Альтернативы и обоснование

- Оставить монитор под микшером (рекомендация агента) — владелец предпочёл экран ровно по постановке; диагностика MIDI остаётся в логе (`tracing`).
- Монитор в модальном окне — не выбран; если понадобится, это отдельная задача из бэклога с восстановлением пути данных по истории git.
- Оставить путь данных монитора «на будущее» без потребителя — отвергнуто: кольцо без читателя только копит потери.
- Необязательные поля статуса после обязательных в одной строке — не помещаются при 80 колонках (обязательные — 65 знаков); правый заголовок рамки с приоритетом обязательных решает это без переноса в другую строку.

## Последствия

- (+) Один взгляд показывает, что выбрано и что сломано; нет контекстных клавиш и фокуса; меньше кода (`app.rs` 441 строка вместо 508, `mixer.rs` 64 вместо 160).
- (−) F-08 (приоритет M в v1) и канальная часть F-10 не выполняются в v1.1; возврат — отдельной задачей. При 80 колонках необязательные поля статуса могут быть скрыты.
