# 0001. Движок синтеза: rustysynth за трейтом SynthEngine

- **Дата:** 2026-10-20
- **Статус:** Accepted
- **Тема:** выбор SF2-синтезатора и изоляция движка

## Контекст

Требуется проигрывать банки SoundFont 2 в реальном времени из аудио-коллбэка без аллокаций (ТЗ §1, N-03). Собственный синтез отложен (ТЗ §3, F-17 — бэклог). Лицензии только MIT/Apache (N-11).

## Решение

Основной движок — `rustysynth` 1.3. Движок изолирован за трейтом `SynthEngine` (сигнатура — ТЗ §3): `note_on`, `note_off`, `control_change`, `program_change`, `pitch_bend`, `render(left, right)`. Запасной движок `oxisynth` подключается за feature `synth-oxi`.

## Альтернативы и обоснование

- `oxisynth` 0.1 — ближе к FluidSynth, SF3, но API 0.x и документация неполная; оставлен запасным.
- `fluidlite` — LGPL и C-сборка, нарушает N-11; отклонён.
- `xsynth-core` — рассчитан на тысячи голосов, избыточен.
- Собственный синтез — 1–2 недели до первого звука и нет SF2; отклонён для v1.0.

`rustysynth`: стабильный API 1.x с 2023 года, ноль зависимостей, встроенные реверб и хорус, `render` в f32-срезы без аллокаций.

## Последствия

- (+) Первый звук за 1–2 дня; смена движка — одна реализация трейта.
- (−) Ограничены API крейта (нет per-channel tuning); редкие генераторы SF2 могут звучать неверно — снижение риска через feature `synth-oxi`.
