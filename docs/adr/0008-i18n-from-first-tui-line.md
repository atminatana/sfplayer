# 0008. Локализация rust-i18n с первой строки TUI

- **Дата:** 2026-10-20
- **Статус:** Accepted (OD-3 плана, принято владельцем)
- **Тема:** момент внедрения F-19

## Контекст

F-19 (приоритет M): все строки UI, справки и ошибок в словарях ru/en. ТЗ §8 относит локализацию к этапу 5, после построения всего UI на этапах 3–4.

## Решение

`rust-i18n` и словари `locales/ru.yml`, `locales/en.yml` подключаются на шаге 3.1 вместе с первым экраном. Все строки UI проходят через `t!()` с первого коммита TUI. Этап 5 содержит только проверку полноты словарей и выбор языка (`ui.lang` → системный → `en`). Отклонение от порядка ТЗ §8 — только по времени, не по содержанию.

## Альтернативы и обоснование

- По ТЗ, на этапе 5 — рефакторинг всех строк двух этапов, высокий риск пропустить литерал.

## Последствия

- (+) Нет рефакторинга; тест полноты словарей и grep литералов в `ui/` действуют с этапа 3.
- (−) Чуть больше работы на шаге 3.1.
