# 0003. Аудио на Windows: только WASAPI shared, без ASIO

- **Дата:** 2026-10-20
- **Статус:** Accepted
- **Тема:** аудиобэкенд на Windows

## Контекст

`cpal` поддерживает ASIO через feature `asio`, требующую ASIO SDK и C++-сборки. ТЗ N-01 требует сборку `cargo build --release` без ручной установки SDK. Заказчик ответил (ТЗ §9): ASIO в v1.0 не нужен.

## Решение

На Windows используется WASAPI в shared-режиме (бэкенд cpal по умолчанию). Feature `asio` не включается.

## Альтернативы и обоснование

- ASIO — меньшая задержка, но SDK с отдельной лицензией, ломает кроссплатформенную сборку; отклонён заказчиком.
- WASAPI exclusive — cpal не поддерживает выбор режима напрямую; не рассматривается.

## Последствия

- (+) Сборка на чистой машине с MSVC-тулчейном Rust.
- (−) На части драйверов задержка в shared-режиме может превышать 15 мс — замер на этапе 6 (шаг 6.2), рекомендация буфера в README.
