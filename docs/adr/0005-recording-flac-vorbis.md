# 0005. Запись в FLAC / Ogg Vorbis, кодирование в отдельном потоке

- **Дата:** 2026-10-20
- **Статус:** Accepted
- **Тема:** формат и архитектура записи выходного сигнала (F-20)

## Контекст

Заказчик запросил запись в сжатый формат, не WAV (ТЗ §9). Аудио-коллбэк не может кодировать (N-03).

## Решение

Два формата на выбор пользователя в диалоге F6: FLAC (`flacenc`, pure Rust, без потерь) и Ogg Vorbis (`vorbis_rs`, качество `record.vorbis_quality`). Коллбэк пишет interleaved f32 в SPSC-кольцо `rec_samples`; отдельный поток читает кольцо и кодирует в файл `record.dir/YYYY-MM-DD_HH-MM-SS.{flac,ogg}`.

## Альтернативы и обоснование

- WAV — проще, но отклонён заказчиком.
- Только FLAC — не покрывает запрос на формат с потерями.
- Кодирование в UI-потоке — UI не должен блокироваться на диске.

## Последствия

- (+) Коллбэк не зависит от скорости диска и кодека.
- (−) `vorbis_rs` собирает libogg/libvorbis через `cc` — нужен C-компилятор; feature `vorbis` включена по умолчанию, но отключаема; переполнение `rec_samples` считается и показывается как потеря в статусе.
