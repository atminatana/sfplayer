# 0007. Секции конфига: [keyboard] для нот, [keys] для команд

- **Дата:** 2026-10-20
- **Статус:** Accepted (OD-2 плана, принято владельцем)
- **Тема:** структура TOML-конфига для переопределения клавиш

## Контекст

ТЗ §6 называет и `[keyboard]` (раскладка нот, октава, velocity, `gate_ms`), и `[keys]` (переопределение раскладок) без разграничения.

## Решение

Две секции:

- `[keyboard]` — текстовое пианино: `white`, `black` (строки клавиш), `octave_down/up`, `velocity_down/up`, `gate_ms`, альтернативы для терминалов без Ctrl+стрелок;
- `[keys]` — командные горячие клавиши: `command = "F2"`-подобные пары, переопределяющие таблицу ТЗ §6.

Конфликт двух команд на одной клавише — ошибка загрузки с указанием ключа.

## Альтернативы и обоснование

- Одна секция `[keyboard]` — смешивает ноты (строка символов) и команды (имя команды → клавиша); разная структура значений.

## Последствия

- (+) Понятные имена; независимая валидация.
- (−) Два места для настройки клавиш — документируются рядом в README.
