## Расхождения с ТЗ и уточнения

- **D-06:** поле вмещает имя устройства до 28 знаков, а не до 30: иначе на сетке 96 колонок не остаётся места частоте и размеру блока. ТЗ уточнено на шаге 1.2; оба устройства владельца (по 27 знаков) входят целиком.
- **Подпись после поля:** `48000 Hz / 480  OK` — без слова «кадров», и число — действующий размер блока, а не запрошенный (Д-3). Ключи словаря `header.buffer`, `header.buffer_default` удалены.
- **E-01:** добавлены моноформаты — гарнитурный профиль Bluetooth стерео монопольно не принимает. ТЗ уточнено на шаге 2.2.
- **Контракт `--list-devices`:** у строк `WASAPI Exclusive` диапазон буфера — «unknown», а не «from N frames»: пределы узнаются только открытием. Контракт в ТЗ §5 исправлен.
- **E-06:** «первая другая строка списка» вместо «первая строка, которая открылась» — по словам владельца «первый пункт из списка»; сообщение об откате — в строке сообщений под «Записью», а не в строке «Выход» (в ней после поля осталось 20 ячеек). ТЗ и ADR 0019 уточнены на шаге 2.3.
- **Обрезка с `…`** действует для всех трёх выпадающих списков, не только для аудиовыхода: механизм общий.
- **После верификации (23.11.2026):** владелец услышал шум и мусор в монопольном режиме на «Динамиках». Критерий К-5 был отмечен ✓ по открытию потока, а звук на слух не проверялся — это стояло в «Не проверено» и оказалось ошибкой формата. Исправление и повторная проверка — `docs/done/`, раздел «После плана — мусор в монопольном режиме на 24 битах».

## Не проверено

- **Сборка и тесты на Linux:** целевая платформа Linux на этой машине не установлена. Код для Windows закрыт `cfg(windows)`, но компиляция остального на Linux подтвердится только CI или сборкой владельца.
- **На слух** — проверено владельцем 23.11.2026, после верификации: через провод паузы нет уже в обычном режиме (исходная пауза — задержка Bluetooth-наушников); монопольный режим на «Динамиках» звучит чисто после исправления формата 24 бит; сборка с `asio` через `[ASIO]: Realtek ASIO` работает.
- **Вживую в окне:** выбор выхода из списка, перезапуск с сохранённым выбором, сообщение об откате, вид строки с настоящим размером блока.
- **Отключение устройства во время игры** в монопольном режиме: по коду поток останавливается с записью в лог.
- **Шаг CI со сборкой `asio`** — первый прогон на GitHub после push.
