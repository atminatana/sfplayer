## Критерии приёмки v1.0 (ТЗ §8)

- [ ] Нота с MIDI-клавиатуры звучит на трёх ОС с задержкой ≤ 15 мс — **✗ не проверено**: нет MIDI-устройства и машин Linux/macOS (`[data needed]`). Цепочка MIDI → кольцо → синтез → аудио покрыта тестами по звеньям и живым запуском потока на Windows.
- [x] Все требования M выполнены — по таблице выше все M имеют код и тесты; живые проверки F-02/F-03/F-04/F-14 отмечены ◐.
- [ ] 10 минут без xrun и падений; отключение/подключение MIDI — **✗ требует живого прогона**.
- [x] Клавиши §6 работают, справка F1 совпадает с раскладкой, ноты с текстовой клавиатуры попадают в монитор MIDI — тесты `keys/tests.rs`, `app/tests.rs`, `fulfil(Request::Notes)` добавляет записи в монитор.
- [x] `cargo test`, `cargo clippy -D warnings` зелёные локально (173 passed); CI на трёх ОС — **не запускался**.

## Расхождения с ТЗ, принятые в ходе работы

1. F-12 «активные голоса» показываются как удерживаемые ноты (API rustysynth) — см. `docs/done/`, шаг 4.4.
2. Клавиши для реверба/хоруса (Alt+R/Alt+C) и управление omni-каналом (только конфиг) — в ТЗ не заданы, назначены мной.
3. Пересканирование — F8, а не «клавиша r» из таблицы рисков ТЗ §9 (ADR 0004).
4. Конфиг лежит в `%APPDATA%\sf2_player\config\` (конвенция `directories`), а не в `%APPDATA%\sf2_player`.
5. Словарь — один файл `locales/app.yml` (v2) вместо `ru.yml`/`en.yml` из ADR 0008.
6. `SynthEngine` получил дополнительный метод `max_voices()` с умолчанием (дополнение к сигнатуре ТЗ §3).
7. Зависимость `option-ext` (MPL-2.0) — вне «MIT/Apache» N-11.
