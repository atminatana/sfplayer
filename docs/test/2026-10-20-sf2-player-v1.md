## Шаг 1.2 (2026-10-20)

**Состав** — `src/synth/bank.rs` (4 теста), `src/synth/rusty.rs` (7 тестов); все на `assets/sin_wave.sf2`, 48 кГц, окно 100 мс (4800 кадров).

| Тест | Что проверяет |
|------|---------------|
| `loads_test_bank_with_presets` | банк загружается, первый пресет «Sine Wave», bank 0 |
| `bank_name_comes_from_info_chunk` | имя «User Bank» из INFO |
| `missing_file_is_open_error` | несуществующий путь → `SynthError::Open` |
| `non_sf2_file_is_invalid_error` | `Cargo.toml` как банк → `SynthError::InvalidSoundFont` |
| `silence_before_any_note` | RMS = 0 до первой ноты |
| `note_on_produces_sound_on_both_channels` | RMS > 0.01 на L и R |
| `note_off_lets_sound_decay` | через 1 с после note_off RMS < 10 % от звучащего |
| `all_notes_off_controller_silences_channel` | CC 123 → RMS < 0.001 |
