1. Одинарная рамка на всё окно. На рамке. С левой стороны с отступом 1 от угла левого название программы "sf2_player", с правой стороны с отступом 1 от угла правого название версии "0.3.0"
На рамке внизу как сейчас: "Голоса 0/64 cpu 3% xrun 0" и с правой стороны "движок: SF2 · Stein Grand Piano.SF2"
Все внутренние элементы интерфейса должна отстоять от рамки на 2 ячейки по горизонтали и 1 ячейке по вертикали.

2. Отрисовка клавиатуры. Вот шаблон:
│  │s│ │d│
│  └┬┘ └┬┘
│ z │ x │ 

При нажатии клавиши подсвечивается (инвертируется или меняется фон) у нажатой буквы.

3. ИСТОЧНИКИ MIDI, ОБРАБОТЧИК (переименовать в ДВИЖОК), ВЫХОД, АУДИО-ФАЙЛ (переименовать в ЗАПИСЬ) находятся поверх горизонтальных линий. Над линией и под ней должна быть пустая строка отступа. Пример:

│  ─ ЗАПИСЬ ────────────────────────────────────────────────────  │

4. Блок ВЫХОД и ЗАПИСЬ должны выравниваться к нижней границе окна

5. Блок ЗАПИСЬ

  Папка для файлов: [/home/roman/downloads/] // кнопка, при нажатии - диалог ввода пути как при нажатии на [Папка для файлов]
            Формат: [FLAC/OGG/MIDI]          // выпадающий список
		  			Запись: [Старт] [Стоп] [Отмена]  записей ещё не было // Эта строка норм
